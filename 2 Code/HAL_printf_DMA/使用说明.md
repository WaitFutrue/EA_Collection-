# 最近更新——2025年4月14日

补充一下**CUBE MX** 的配置

- 找到DMA Settings这一栏，点击ADD添加DMA数据流，这里把发送和接收的DMA全部打开，同时注意DMA的配置，一般的串口都是8位，因此使用默认的DMA配置即可（也就是指针自增为BYTE）：

![CSDN](https://i-blog.csdnimg.cn/blog_migrate/77fe3ca905d745964a3d06176ae17b64.png)

- 此处可以对串口接收的DMA进行更多设置，比如设置DMA模式为Circular，使DMA在一次接收完成后自动开启下一次接收(见下图左下角)

![CSDN](https://i-blog.csdnimg.cn/blog_migrate/2ab1c68633a9ee94c2ab790eaa7f26cf.png)

- 此外，需要在NVIC Setting里面设置打开串口的全局中断，部分型号不打开此中断会出现传输失败的问题（如下图，在方框勾选即可）

![CSDN](https://i-blog.csdnimg.cn/blog_migrate/2f44cc30e00b672b77e39a1c4d7f928d.png)

- 以上，发送就配置好了，注意DMA传输是异步的，非阻塞的，所以若连续调用需注意！若要查看相关以及配置接受，请参考网址👇
